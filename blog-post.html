Designing Large Scale Progression Systems

By Matthew Hager • May 2026

One of the most interesting parts of game development is designing systems that motivate players to continue exploring and improving over long periods of time. Progression systems can completely change how players interact with a world.

“Good progression systems make players feel curious, not just powerful.”

A progression-based game can encourage experimentation, exploration, and long-term planning. I am especially interested in games where players unlock increasingly advanced technology and scientific concepts over time. 


function unlockTechnology(level) {

    if (level >= 10) {
        return "Advanced Engineering";
    }

    return "Basic Technology";

}

Designing systems like these requires balancing pacing, rewards, and player freedom. Future projects could explore procedural systems and evolving game worlds.
